> 分道扬镳——尤其把一个点拖成离群点时,绿线被狠狠拽走,紫线几乎不动。

## 一、问题:一堆散点,哪条直线"最好"?

> **一条直线为什么能用来预测?**
>
> 假设我们想根据身高预测体重:把每个人的身高记在 x 轴、体重记在 y 轴,每个样本
> 就是平面上的一个点。我们要找一条直线 $y = kx + b$,让它给出的预测体重尽量接近
> 真实体重。这里的误差,是在同一身高 x 下,真实体重 y 与直线预测值 $kx+b$ 的差。
> 所以只要找到一条让误差最小的直线,以后输入一个新的 x(身高),读出直线上对应的
> 那个点,就得到了 y(预测体重)。

接下来一步一步拆解,如何找到(拟合出)这样一条预测线。

假设散点大致沿一条直线分布,但每个点都带噪声,所以不会分毫不差地落在拟合出的直线上。
任意画一条直线 y = kx + b,每个数据点 (xᵢ , yᵢ) 和直线之间就有一段竖直的落差,
这段落差也就是预测值到真实值的误差:

$$e_i = y_i - (k x_i + b) \qquad \text{(第 i 个点的残差:实际值减预测值)}$$

在 demo 里勾选「显示残差竖线」就能直接看到这段落差:每个红点到蓝线之间都有
一条竖直虚线,**这条线的长度就是该点残差的绝对值** |eᵢ|。点落在直线**上方**时 eᵢ > 0,
落在**下方**时 eᵢ < 0。拖动某个红点、或拖两个蓝色端点转动直线,对应的虚线就随之伸长缩短——残差是大是小,一眼就看得出来。

"最好的直线"应该让所有残差整体最小。但"整体"怎么定义?直接把残差加起来
不行——上方的正残差和下方的负残差会互相抵消,一条烂线也能得零分。
所以第一步是**先消掉符号**,再求和。消符号最自然的两种办法:

$$\text{平方:}\ \mathrm{SSE}(k,b) = \sum_i e_i^2 \qquad\qquad \text{绝对值:}\ \mathrm{SAE}(k,b) = \sum_i |e_i|$$

> SSE = Sum of Squared Errors,误差平方和,也常叫残差平方和;

> SAE = Sum of Absolute Errors,绝对误差和,也常叫绝对残差和。

 (请记住这两个缩写,后面会反复用到。)

这两种选择,就是本 demo 里绿线和紫线的全部分歧来源。

## 二、平方 vs 绝对值:两种"惩罚哲学"

两种损失都能消掉正负、都随误差单调增大,但它们对"大误差"的态度截然不同。

| | 平方误差 L2(绿) | 绝对值误差 L1(紫) |
| --- | --- | --- |
| 单点代价 | e²(边长为 \|e\| 的正方形**面积**) | \|e\|(残差竖线的**长度**) |
| 对大误差 | **平方放大**:误差翻倍,罚分变 4 倍 | 线性:误差翻倍,罚分才翻倍 |
| 离群点 | 被狠狠拉过去(大错重罚) | 受影响远小于 L2(罚分只线性增长) |
| 误差面形状 | 一只光滑的碗 | 一只带棱的漏斗 |
| 精确求解 | 闭式解(几何投影,见第六节) | 枚举点对精确解(第 3.2 节) |
| 对应统计量 | 均值 | 中位数 |

**demo 把这张表画了出来:**

- 勾选"显示残差的平方",黄色正方形的**面积**就是各点的 L2 罚分,SSE = 总面积;
- 勾选"显示残差竖线",竖线的**长度**就是各点的 L1 罚分,SAE = 总长度。

把一个点往远处拖:它的黄色正方形以**平方速度**膨胀(边长翻倍、面积四倍),
于是绿线被这一个点主导、猛地转过去;而它的残差竖线只是**线性**变长,
对 SAE 的影响有限,紫线几乎不动。

> **这就是全部故事:平方把"大错"放大成主角,绝对值让每个点接近一人一票。
> 前者精确、好算,后者抗噪、稳健。**

要说清楚一点:L1 **不是不受**离群点影响,而是**不容易被单个离群点支配**。
误差从 10 涨到 100,L1 的罚分涨 10 倍,L2 的罚分却涨 100 倍——差距就在这里。

## 三、两条线各自怎么算出来的

### 3.1 L2 闭式解:一步到位的公式(面板绿色的 k*、b*)

先解释一下"闭式解"这个词,不然后面会一直硌着。看一个小学方程:

$$2x + 3 = 11 \quad\Longrightarrow\quad x = 4$$

你不需要把 x 一个个代进去试,而是**移项、除以 2**,一步就把答案算了出来。
凡是能用一个明确的公式、从已知条件**直接算出**答案的,都可以粗略地叫**闭式解**。
它的对立面是"不停试、一点点逼近":

| | 走法 |
| --- | --- |
| **闭式解** | 数据 → 公式 → 最优答案 |
| **数值优化** | 初始值 → 改一点 → 再改一点 → …… → 逼近最优答案 |

最小二乘特殊就特殊在:**它两条路都走得通**——既可以当成一个"不断调 k、b 让误差
下降"的优化问题(第五节就是这么玩的),也可以像解 2x+3=11 那样,直接推出一个公式。
本节先走公式这条路。

先把直线想成有两个旋钮的机器:**k 旋钮**负责让线转得更陡或更平,**b 旋钮**
负责让线整体上移或下移。你每拧一点旋钮,就得到一条新直线;对这条线,把所有点的
误差平方后加起来,就得到一个分数 SSE。分数越小,说明这条线整体越贴近散点。

所以 SSE 是 k、b 的函数,意思只是:**k 和 b 取什么值,SSE 的分数就跟着变。**
可以把所有可能的组合想成一张地形图:横着走是调 k,前后走是调 b,高度就是 SSE。
当直线很不合适时,分数高,位置像在高处;不断调 k、b 让线更合适时,分数降低,
就像沿坡往下走。对于平方误差,这片地形恰好平滑地向同一个最低点凹下去,像一个
没有坑洼、没有棱角的碗:

```text
SSE
 ^
 | .                       .
 |   .                   .
 |      .             .
 |          .     .
 |             *   <- 碗底 = 最优的 k, b
 +--------------------------> k, b settings
```

两边高、中间低,只有一个最低处——那个 `*` 就是让 SSE 最小的 k、b。

这里的"二次曲面"只是这个碗在两个旋钮方向上的数学名称,不必先记住它。最重要的是:
**碗底只有一个**。因此只要找到了最低处,就找到了全局最小的 SSE,不会出现"看似已经
很低、其实旁边还有更低的坑"的陷阱。

碗底(误差最小处)满足一组恰好把残差"用光"的条件——**第六节**会用纯几何(残差
垂直于模型)把它讲透;这里先直接给出一步算到碗底的公式(初中代数就够):

$$k^* = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2} \qquad b^* = \bar{y} - k^* \bar{x}$$

其中 x̄、ȳ 是均值。两个式子各有一句人话:

- **k\*** 的分子是 x 和 y 的"协同变化量",分母是 x 自身的"分散程度"——
  斜率 = y 随 x 变化的部分,占 x 总变化的比例;
- **b\* 的式子等价于:最优直线必过均值点 (x̄, ȳ)**。拖动散点时盯着绿线,
  它始终穿过数据的"重心"。

分母 Σ(x−x̄)² 是关键:把所有点拖成一条竖线(x 全相同),分母为零,公式失效——
面板显示"—",这不是 bug,是数学在报错。

不过要说准确一点:此时**并不是"最好的预测不存在"**。x 全等于 x₀ 时,直线给出的
预测 ŷ = k·x₀ + b 无论怎么调都只是**一个常数**,而让 SSE 最小的那个常数就是 ȳ,
它照样存在、照样唯一。出问题的是 **k 和 b 这两个参数**:凡是满足 k·x₀ + b = ȳ 的
(k, b) 组合有无穷多种,它们给出的预测一模一样,数据没法告诉你该选哪个。
所以这里失效的是"解**唯一**",不是"解**存在**"——第六节会看到它的几何原因。

### 3.2 L1 没有统一的闭式公式,但最优线总能"穿过两个点"

绝对值在零点有个尖角,SAE 这个"碗"是一堆平面折出来的、带棱的漏斗,
没有像 3.1 那样一步到位、对任意数据都成立的公式——严格说它是个**线性规划**问题。

(注意别把话说过头:**L1 不等于"永远没有闭式解"**。第四节就会看到,模型退化成
一条水平线 y = c 时,L1 的解是**中位数**——那也是个闭式解。没有统一公式的是
带斜率的一般情形。)

但 L1 有个漂亮而实用的性质:

> **总能找到一条让 SAE 最小的直线,它穿过其中两个数据点。**

直觉:如果一条线没贴住任何点,你总能朝"多数点所在的一侧"平移或转动它,
让 SAE 继续下降,直到被某些点"顶住"为止——最优解总能卡在某两个点上。

注意这是个**存在性**结论,不是"每一条最优线都必须穿过两个点":最优解不唯一时
(比如有一整片同样好的解),其中也可以有不贴任何点的。但只要**存在**一条穿过两点的
最优线,枚举点对就一定能把它找出来。

这条性质让精确求解变得很简单,**demo 就是这么算紫线的**:枚举所有点对
(n≤15,最多 C(15,2)=105 对),每对确定一条候选直线,算出它的 SAE,
取最小的那条。代码见 `bestFitL1()`。x 相同的点对(竖线)跳过;所有点 x
全相同时 k、b 同样定不下来,面板显示"—",和 L2 一样。

(真实世界里点很多时不会枚举点对,而是用**线性规划**或**迭代重加权最小二乘
IRLS** 求解,但对一个十来个点的 demo,枚举点对既精确又直白。)

## 四、更深一层:均值 vs 中位数

把直线退化到最简单的情形能看得更透:如果模型只是"一条水平线 y = c"
(只有截距、没有斜率),那么两种损失分别在求什么?

- **L2:** 让 Σ(yᵢ − c)² 最小的 c,是所有 yᵢ 的**均值**;
- **L1:** 让 Σ|yᵢ − c| 最小的 c,是所有 yᵢ 的**中位数**。

第二个结论很好证:c 每往右挪一小步 dx,**左边**每个点的 |误差| 各增加 dx,
**右边**每个点各减少 dx,所以

净变化 = (左边点数 − 右边点数) × dx

只要两边点数不等,往点多的那一侧挪总能让 SAE 下降;**只有两边点数相等时,
往哪边挪都不划算**——那正是**中位数**。

(点数为偶数时,中间那两个点之间的**一整段**都让两边点数相等,SAE 在这段上是条
水平线,整段都是最优解。所以"偶数个数取中间两个的平均"只是个约定,数学上那一段
里每个值都同样好。)

而均值 vs 中位数正是"抗噪"差别的最小版本:一个亿万富翁走进小酒馆,
平均收入暴涨(均值被离群值拽走),中位数几乎不变。L2 继承了均值的敏感,
L1 继承了中位数的稳健——demo 里那条紫线,就是这份稳健在二维上的样子。

> **L2 : 均值 = L1 : 中位数。斜率一加进来,故事不变,只是从"一个数"
> 升级成"一条线"。**

## 五、一步一步"凭感觉"拟合:两个「试探法」按钮

绿线、紫线是**一步到位**算出来的最优解。既然公式这么好用,为什么还要一步步试?

> 如果目标只是拟合这一条直线,直接套 3.1 的闭式解最快,试探法纯属绕远路。
> 这里仍然演示"一步步逼近",是因为**真正的神经网络通常没有这么方便的闭式解**——
> 而"不断调整参数、让 loss 一点点下降"才是机器学习训练里更普遍的情况。
> 换句话说:闭式解是最小二乘的**特权**,逐步逼近才是常态。

所以不妨换个处境:假如你**不知道**第三节那些公式,只会"给一条直线、算出它的误差",
怎么找到最好的线?最土、也最万能的办法就是——**试**。demo 把这个笨办法交给你,
每点一次按钮走一步。

### 5.1 如何使用这个 demo

先把控件认全,后面几小节讲的机制才对得上号。

1. **散点与直线**:
   - **拖动红点**改变数据;**点击空白处**加新点(最多 15 个);**双击红点**删除它
     (至少要留 2 个点,只剩 2 个时删不掉);
   - **拖动两个蓝色端点**手动调整直线,面板实时显示斜率 k、截距 b,以及这条线的
     两种代价:残差平方和 **SSE** 和残差绝对值和 **SAE**。
2. **两条参考线**(默认都开):
   - **绿色 L2 线**:让 SSE 最小的最小二乘直线,由闭式解算出;
   - **紫色 L1 线**:让 SAE 最小的最小绝对偏差直线,由暴力枚举点对精确算出。
3. **四个开关**:
   - **显示残差竖线**:每个点到蓝线的竖直虚线,长度 = 这个点的"误差";**所有竖线
     的总长度 = SAE**;
   - **显示残差的平方**:以残差为边长的黄色正方形——**面积**就是这个点对 SSE 的贡献,
     **所有黄色面积之和 = SSE**;
   - **显示 L2 最小二乘线 / L1 最小绝对偏差线**:分别开关绿、紫两条最优参考线。
4. **三个按钮**(拟合是**一步一步**走的,用不带导数的**试探法**,每点一次只走一步;
   它到底怎么试探,见下一小节):
   - **L2 · 最小二乘试探一步**:让蓝线朝 SSE 变小的方向迈一步;反复点它,
     一步步逼近绿线;
   - **L1 · 绝对值误差试探一步**:同一套办法,只是改看 SAE,逼近紫线;
   - **重置数据**:恢复初始散点与直线。
5. **「试探法」框**在面板上方,每走一步都会摊开这一步的细节(每项数字是什么意思,
   同样见下一小节)。另外两条行为要知道:
   - 拖动散点或直线端点会**清空步数、重新开始**;
   - **收敛到最优后,对应按钮会自动变灰、无法再点**(试探步长已缩到近乎为零,
     再点也不会动);想继续玩就拖动散点/端点改变数据,或换另一个按钮。

先手动拖蓝线,试着把 SSE 或 SAE 压到最小,再和绿线、紫线比一比;然后交给按钮,
一步步看它怎么凭感觉试探着挪。最后**把一个红点拖到很远**,盯着绿线和紫线的不同反应。

### 5.2 试探法(爬山)怎么走

站在当前这条蓝线上,朝四个方向各试探一小步:

- **斜率调大 / 调小**(把线绕着转一点点)——对应 k+δ、k−δ;
- **截距调高 / 调低**(把线整体上下平移一点点)——对应 b+δ、b−δ。

每个方向都算一下误差(L2 按钮看 SSE,L1 按钮看 SAE),**四个里挑误差最小的那个,
就往那儿挪**。步长 δ 会自己调:

- **挪成功了**——说明这个方向确实在下坡,就把**这个方向**的 δ 放大一点(×1.3),
  下一步迈得更大,下山更快;
- **四个方向都没能让误差更小**——说明快到谷底、步子迈过头了,就**把两个方向的 δ
  一起减半**,原地不动,下一次试得更精细。

如此反复,直到 δ 趋近于 0,蓝线停在绿线 / 紫线上。所以面板上的 δk、δb 是**时大时小**
的:顺风时变大,撞墙时折半,而不是一路单调变小。

面板的「试探法」框把每一步都摊开给你看:四个方向各自的误差、这步选了谁、
k 和 b 怎么变、走了多大步、当前试探步长、误差从多少降到多少、离最优还差多远。
你能一眼看到它怎么"摸黑下山"。

### 5.3 笨,但通用——因为它不需要导数

关键是:整个过程只用到两件事——**会算误差、会比大小**。没有公式、没有求导。
正因如此,它对平方(SSE)和绝对值(SAE)**一视同仁**:同一套按钮、同一套逻辑,
换个误差就能用。这就是"笨办法"的好处——无脑、通用,什么损失都能试。

代价也很明显:每一步都在**盲试**四个方向,还常常空试(减半那几步其实原地没动);
越接近谷底越慢,要几十步才彻底收敛。你自己点上十几下就会冒出一个念头:

> **能不能不用盲试,就直接知道"往哪个方向下坡最快、该迈多大步"?**

能。那需要一个新工具——**导数**。导数能算出误差在当前直线处的"下坡方向和陡峭
程度",于是一步就朝最优方向精准迈进,不用四处试探。这就是**梯度下降**。

### 5.4 顺带一提:两种损失给的"下坡信号"不一样

既然提到了导数,正好可以看清 L1 和 L2 更深一层的分歧。把单个点的罚分对残差求导:

$$L = e^2 \ \Longrightarrow\ \frac{\mathrm{d}L}{\mathrm{d}e} = 2e
\qquad\qquad
L = |e| \ \Longrightarrow\ \frac{\mathrm{d}L}{\mathrm{d}e} = \begin{cases} +1, & e > 0 \\ -1, & e < 0 \end{cases}$$

导数就是这个点"往哪边推、推多用力"的信号:

- **L2 的推力正比于误差本身**:错得越离谱,推得越使劲。所以它收敛快、信号强,
  但一个离群点能喊出普通点几十倍的音量;
- **L1 的推力恒为 1**:不管错 10 还是错 100,每个点使的劲一样大。所以它稳,
  但接近最优时信号也不会变弱,反而不容易精细收敛(而且 e = 0 处不可导)。

这正是第二节那张表在导数层面的样子。**但别把它读成"L2 永远更好"**:
"误差越大、修正越强"在数据干净时是优点(收敛快),在有脏数据时就是缺点
(被离群点牵着走)。选哪个损失,取决于你的数据有多脏,而不是哪个数学上更漂亮。

### 5.5 更聪明的下山法,留给下一个 demo

**下一个 demo(微分 · 导数)会专门讲导数,然后用梯度下降回来取代这里的试探法**
——同一只碗,聪明地下山:方向不靠试、靠算,步子更少、更准。

顺带一提:真实神经网络的训练用的就是这个"聪明下山",只是把 2 个参数(k、b)
换成成千上万个。**线性回归可以看成最简单的"神经网络"**(一个神经元、恒等激活、
均方误差损失);本节的试探法是它的"无导数平民版",先帮你把"一步步逼近最优"
的直觉建起来,等导数到位,机器就换上更快的鞋。

至于"最优到底长什么样"——为什么碗底那个点就是最好的——不用等下一个 demo,
**紧接着的第六节就会用纯几何回答**。

## 六、L2 的几何:最小二乘 = 一次投影

这一节只讲绿线(L2)——因为"投影"这套漂亮的几何,恰恰依赖平方(欧氏距离),
换成绝对值就没有了。这是「点积」demo 结尾埋的伏笔,现在回收。

### 6.1 先拿三个点当跳板

直接跳到"n 维空间"太抽象,先用三个点走一遍。假设数据是

(1, 2)、(2, 3)、(3, 5)

三个真实的 y 值是 2、3、5。**别再把它们看成三个分散的数字,而是打包成一个
三维向量**:

$$\mathbf{y} = (2, 3, 5)$$

这个三维空间的三条轴,不是长宽高,而是"第 1 个样本的 y""第 2 个样本的 y"
"第 3 个样本的 y"——**有多少个样本,就有多少维**。

关键的一步:**每选一组 (k, b),就得到一个完整的预测向量**。比如

- y = x + 1 在 x = 1, 2, 3 处给出 ŷ = (2, 3, 4);
- y = 2x 在同样三点给出 ŷ = (2, 4, 6)。

**散点图上的一条候选直线,就是这个空间里的一个点。** 而所有可能的预测写出来是:

$$\hat{\mathbf{y}} = (k+b,\ 2k+b,\ 3k+b) = k(1,2,3) + b(1,1,1)$$

自由参数只有 k、b 两个,所以 ŷ 永远只能是 (1,2,3) 和 (1,1,1) 这两个方向的组合。
它**填不满**整个三维空间,只能落在这两个方向张成的一张**二维平面**上。

> **这里最容易绕晕**:这张平面**不是** x-y 散点图里那条拟合直线。
> 它活在"所有预测结果组成的空间"里;散点图上的每一条候选直线,对应的是
> 这张平面上的**一个点**,而不是平面本身。

### 6.2 换成 n 个点,一字不变

把 3 换成 n,道理完全一样:把所有观测值**竖着堆成一个向量**

$$\mathbf{y} = (y_1, y_2, \ldots, y_n) \qquad \text{(n 维空间里的一个箭头)}$$

直线能产生的预测也是一个 n 维向量,而且仍然只有两个自由度:

$$\hat{\mathbf{y}} = k \cdot (x_1, \ldots, x_n) + b \cdot (1, \ldots, 1)$$

k 和 b 随便取,所有可能的预测 ŷ 张成 n 维空间里的一张**二维平面**(模型平面)。
真实观测 y 因为带噪声,一般**不在**这张平面上。

这就是**模型空间**的真正含义。假设你有 100 个样本,y 是个 100 维向量;可线性模型
只有 k、b 两个自由参数,能吐出来的答案永远只是这 100 维空间里的一张二维平面——
**模型能表达的答案,只占整个可能空间中极小的一部分**。于是:

> **拟合的本质,不是"画一条靠近散点的线",而是"在模型允许表达的所有答案里,
> 找出离真实答案最近的那一个"。**

> 想**亲手拖着看**这张模型平面、看残差怎么随"垂直程度"由灰变绿,去隔壁的
> [正交投影 · 最小二乘的几何本质](../orthogonal-projection/)——那个 demo 专门
> 把本节画成了可交互的三维场景,还配了欧氏距离的详细注解。

### 6.3 为什么"平方误差最小"就是"找最近的点"

残差也是一个向量:**e** = **y** − **ŷ**。它的长度是各分量平方和再开根号,所以

$$\lVert \mathbf{e} \rVert^2 = e_1^2 + e_2^2 + \cdots + e_n^2 = \sum_i (y_i - \hat y_i)^2 = \mathrm{SSE}$$

也就是说,**SSE 本来就是"真实向量 y 到预测向量 ŷ 的欧氏距离的平方"**。
最小化平方误差,和让这两个向量之间的距离最短,是**同一件事**。
于是"找最好的直线"变成了一个纯几何问题:

> **在模型平面上,找离 y 最近的那个点。**

答案你在「点积」demo 里已经见过:**把 y 垂直投影到平面上**。悬在地面上方的一个点,
垂直落到地面的那一点,才是地面上离它最近的点,斜着落永远更远。

```text
              * y    (观测向量, n 维空间中一点)
             /.
            / .
           /  .      <- 残差向量 e = y - yhat, 垂直于平面
          /   .
         /    .
   -----+-----+----------------
        O     yhat   (y 在模型平面上的投影 = 最小二乘的预测)
```

"最近" = 残差向量 e 最短,而 SSE 恰好就是 |e|²(平方和 = 长度的平方,
「点积」demo 3.4 的副产品 a·a = |a|²)。垂直投影最短,所以:

> **最小二乘的解 = y 在模型平面上的投影;残差向量 ⊥ 模型平面。**

"垂直"翻译成代数,就是两个点积为零(e 和平面的两个方向都零贡献——
「点积」demo 2.2 那个"垂直 = 互不贡献"):

$$\mathbf{e} \cdot (x_1, \ldots, x_n) = 0 \qquad \mathbf{e} \cdot (1, \ldots, 1) = 0$$

把这两个点积展开,得到的正是 3.1 节的闭式解——教科书管它叫**正规方程**。
(为什么 L1 没有这套?因为 SAE = Σ|eᵢ| 不是欧氏长度的平方,"最近"不再是
垂直投影,勾股定理失效,漂亮的正交几何就散了。)

### 6.4 写成矩阵:正规方程的标准形

上面那两个点积其实可以合并成一个式子。把 x 和全 1 这两个方向**并排立成两列**,
得到**设计矩阵** X;把两个参数并成一列,得到 θ:

$$X = \begin{bmatrix} x_1 & 1 \\ x_2 & 1 \\ \vdots & \vdots \\ x_n & 1 \end{bmatrix}, \qquad \theta = \begin{bmatrix} k \\ b \end{bmatrix}$$

X 有 n 行(每个样本一行)、2 列(k 和 b 各一列)。于是"直线能产生的所有预测"
写起来就短短一行:

$$\hat{\mathbf{y}} = X\theta \qquad\qquad \text{目标:} \ \min_{\theta}\ \lVert \mathbf{y} - X\theta \rVert^2$$

而"残差同时垂直于 X 的两列",正好就是 Xᵀ 乘上残差等于零:

$$X^{\mathsf T}(\mathbf{y} - X\theta) = 0 \quad\Longrightarrow\quad X^{\mathsf T}X\,\theta = X^{\mathsf T}\mathbf{y}$$

这就是**正规方程**的标准写法。当 XᵀX 可逆时,两边左乘它的逆:

$$\theta = (X^{\mathsf T}X)^{-1} X^{\mathsf T}\mathbf{y}$$

把这个只有两列的情形逐项展开,得到的就是 3.1 节那两个 k\*、b\* 的公式
——**同一件事的两种写法**。

三处呼应在这里收拢:

- **它不是凭空冒出来的公式**,只是"残差 ⊥ 模型平面"这句几何话的代数翻译;
- **XᵀX 什么时候不可逆?** 正是 X 的两列线性相关的时候——也就是 x 全相同、
  x 与全 1 向量平行,模型平面从二维塌成一维。这恰好是 3.1 节末尾那个
  "分母为零"的退化情形:投影依然存在且唯一,但它的 (k, b) 坐标不唯一;
- **换成多个特征也一字不改**:X 多几列而已,正规方程长得一模一样。

### 6.5 "梯度为零"和"残差垂直"是同一句话

第五节结尾说,导数能告诉你往哪边下坡;碗底就是坡度为零的地方。把 SSE 对两个旋钮
分别求导,会得到一个漂亮得有点意外的结果:

$$\frac{\partial\,\mathrm{SSE}}{\partial k} = -2\,(\mathbf{e} \cdot \mathbf{x})
\qquad\qquad
\frac{\partial\,\mathrm{SSE}}{\partial b} = -2\,(\mathbf{e} \cdot \mathbf{1})$$

于是"**梯度 = 0**"这个微积分条件,展开就是 **e · x = 0** 且 **e · 1 = 0**,
也就是"**残差 ⊥ 模型平面**"这个几何条件——**同一件事的两种说法**:

> 微积分说"坡度为零",几何说"残差垂直",代数说"正规方程"。
> 三张嘴,讲的是碗底那同一个点。

### 6.6 两个空间,同一个最优解

最后把整篇文章的两张图拼起来。你手上其实一直有两个空间:

- **参数空间**:动的是 (k, b),就是 3.1 节那只**碗**——k、b 是你能拧的旋钮;
- **预测空间**:动的是 ŷ,就是本节这张**模型平面**——ŷ 是拧完旋钮后模型真正
  给出的答案。

拧一下旋钮,碗上的位置挪一点,平面上的预测点也跟着挪一点,两者一一对应。所以:

> **碗底和垂足,其实是同一个最优解在两个空间里的不同样子。**

三个 demo 到此串成一条线:

> **cos 量影子(点积 demo)→ 神经元打分是投影(点积 demo 第四节)→
> 最小二乘是把观测投影到模型空间(本 demo)。同一只影子,三个尺度。**

## 七、试试这几种情形

- **制造一个离群点(本 demo 的招牌)**:把某个红点拖到很远,盯着两条线——
  绿线(L2)被它以平方速度膨胀的黄色正方形拽着猛转,紫线(L1)几乎不动。
  这是"平方大错重罚 vs 绝对值人人推力相同"最直观的对照,也是脏数据场景改用
  **稳健回归**(L1 / Huber)的全部理由;
- **一步步摸黑下山**:从歪的蓝线开始,反复点「L2 试探一步」,盯着面板——四个
  方向的误差此消彼长、步长 δ 在"空试"后一次次减半,越接近谷底走得越慢;再用
  「L1 试探一步」跑一遍,对比两者试探的路径和步数,亲身体会笨办法的又通用又慢;
- **先制造离群点,再让两个按钮各跑到底**:拖出一个坏点后分别按到收敛,
  蓝线停在绿线时被坏点拽偏、停在紫线时几乎没动——用"拟合的终点"再确认一次
  两种损失的性格;
- **手动挑战最优**:关掉绿、紫两条参考线,拖蓝线把 SSE 压到最小,再打开
  绿线看差多少;换个目标把 SAE 压到最小,再打开紫线——你会发现让 SSE 最小
  和让 SAE 最小往往**不是同一条线**;
- **只留两个点**(双击删掉其余):两点确定一条直线,SSE 和 SAE 同时压到 0——
  绿线紫线重合,谁都完美,也谁都没学到规律;
- **让数据很"干净"**:噪声很小、没有离群点时,绿线和紫线几乎贴在一起——
  两种损失只在有坏点时才吵架,数据老实时它们意见一致;
- **把点排成竖线**:x 全相同,面板 k* 和 L1 的 k 都显示"—"。注意这不是
  "算不出最好的预测"——最好的预测还是 ȳ,只是能凑出这个预测的 (k, b) 有无穷多组,
  数据没法告诉你选哪个。几何上就是模型平面塌成了一条线(见 6.4 节 XᵀX 不可逆);
- **从很离谱的直线开始试探**:不管起点多差,SSE 的碗只有一个底,试探法总能
  一路挪到绿线——二次碗里没有"局部最优"陷阱,连笨办法都不会走岔,这是线性 L2
  模型比深度网络幸福的地方。

## 八、它通向哪里

整篇文章其实是一条链子,每一环都扣着下一环:

> **残差 → 损失函数 → 距离 → 模型空间 → 正交投影 → 最优解 → 导数 → 梯度下降**

如果只带走一句话,带走这句:

> **最小二乘的本质,不只是"让几个误差的平方之和最小",而是——
> 在模型能够表达的所有答案中,寻找距离真实答案最近的那一个。**

而机器学习训练做的事情本质上也是同一件:在模型能表达的巨大参数空间里,
找一个尽可能好的答案。往下走:

- **均方误差(MSE)**:把 SSE 除以 n 就是 MSE——神经网络做回归任务时的
  标准损失函数,和 what-is-nn 里的交叉熵是姊妹;
- **稳健回归**:L1(最小绝对偏差)、Huber 损失等专门为"有离群点/脏数据"
  设计,本 demo 的紫线就是最朴素的一员;深度学习里同样常用 L1/Huber 来
  压低异常样本的影响力;
- **线性探针**:研究大模型内部表征的常用工具——拿隐藏层向量对目标做一次
  线性回归,看"这个信息是否被编码了";
- **多元与非线性**:把"一条直线"换成"多个特征的加权和",L2 的闭式解与投影
  几何一字不改,只是模型平面升维。但换成**非线性**模型就不一样了:模型能表达的
  答案不再是一张平的平面,而是一张弯曲的曲面,"整体正交"这件事一般不再成立,
  能保留的只是"沿曲面局部方向的变化率为零";
- **下一个 demo(微分 · 导数)**:本文的试探法只会"盲试四个方向",慢而通用;
  导数能一口报出"最陡的下坡方向和坡度",于是把盲试升级成**梯度下降**,
  精准地取代这里的笨办法——割线逼近切线的故事,正好接在后面。
  对复杂神经网络,一般不存在像线性最小二乘这样简单实用的闭式解,
  所以实际训练基本都依赖这类基于梯度的数值优化方法。
